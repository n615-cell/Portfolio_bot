# 🤖 Бот-портфолио «Моя вселенная»

**Telegram-бот, который рассказывает обо мне — от творчества до кода.**

---

## 🌟 О проекте

Этот бот — моё интерактивное портфолио. Здесь я собрала всё, что меня вдохновляет: книги, которые я люблю, арты, которые рисую, проекты, которые создаю, и людей, которые помогли мне вырасти.

Бот создан для конкурса портфолио **CapEducation** и написан на **Python** с использованием библиотек `pyTelegramBotAPI`, `matplotlib` и других.

---

## ✨ Фишки бота

- **8 блоков-разделов** — обо мне, моих целях, менторах, прогрессе, хобби, проектах и книгах.
- **Интерактивные меню** — многоуровневая навигация с возвратом в предыдущие разделы.
- **Встроенная викторина** — 3 уровня сложности с проверкой знаний обо мне.
- **Блок вопросов** — 15 вопросов, на которые бот отвечает сам (без ИИ).
- **Динамические графики** — два графика: «Навыки в IT» (радар) и «Творческие навыки» (столбцы).
- **Галерея артов и этапов** — пролистывание рисунков и процесса работы.
- **Смена темы по времени суток** — утро, день, вечер, ночь — разное приветствие и настроение.
- **Обработка ошибок и автоперезапуск** — бот не падает, а перезапускается при сбое.

## 🛠 Технологии

| Технология | Назначение |
|------------|------------|
| **Python 3.9+** | Язык программирования |
| **pyTelegramBotAPI** | Работа с Telegram API |
| **matplotlib** | Генерация графиков |
| **Pillow** | Обработка изображений |
| **python-dotenv** | Хранение переменных окружения |
| **requests** | Работа с внешними ссылками |
